# Gallery Images

Place your portfolio images in this folder.

## Image naming convention:
- Name your images sequentially: `1.jpg`, `2.jpg`, `3.jpg`, etc.
- Or use: `1.png`, `2.png`, `3.png`, etc.
- Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`

## How it works:
The gallery component automatically scans this folder and displays all images in order.
